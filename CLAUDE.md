# ansible-course

Static Ansible course site, served by GitHub Pages straight from this repo (no build step).

## Working rules

- Follow the Superpowers workflow (brainstorming → spec → writing-plans → execution) in `.claude/skills/`.
- Ponytail applies at every stage, including execution under Superpowers skills: take the laziest solution that works, no unrequested abstractions, no new dependencies when the platform or stdlib covers it.
- Ponytail never cuts exercise correctness: every exercise keeps its reference solution and wrong-answer tests.
